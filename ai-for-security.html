AI-AMPLIFIED SECURITY · ATTACK FOUNDATION MODEL · HORIZONTAL BASE-LAYER VIEW

“用 AI 提升网络安全”行业图谱与攻击基座大模型专题（底座层重算版）

5 个三级、16 个四级能力；关键修正——攻击基座大模型（中国版 Mythos）不是 593.5 亿盘子里的一个小切片，而是横跨“用 AI 做安全 + 保护 AI 安全”两个二级市场的共享底座，U2–U5、姊妹篇 T1–T5、软硬一体机与省市服务商皆是其客户，具数据飞轮。本版以“底座层渗透法”自下而上重算其规模与增速。

核心结论：①专用安全基座是独立品类——同代模型专用版 GPT-5.6-Cyber 完成 95% 高级攻防、通用版仅 1.5%，微软 5B 小专用模型反超 Mythos 12 分且成本减半，胜负手是攻防数据 / 工作流 / 系统而非参数规模；②攻击基座客户横跨两个二级，重算后中国 2025 约 2.8 亿 → 2030 中性约 190 亿元（区间 127–268 亿）、CAGR≈133%，远高于此前切片口径；③格局为 约 2 家纯软件 + 1–2 家软硬一体安全基座寡头，上承应用层百花齐放、下接省市服务商；④字节 / 智谱 / Kimi / MiniMax / 千问 / DeepSeek 因机会成本、对美制裁顾虑与 AGI/ASI 主战略，只做开源通用上游、不做安全基座生意（DoGNAVY 建在 GLM-5.2 上即是现实样本），窗口留给达酷诺威这类专业团队；⑤规模采用“三口径阶梯 + 底座层渗透”并经两位一线专家（无糖张瑞东、某头部一线安全厂商安全实验室负责人）交叉校验，结论是壁垒在攻防数据与运行时控制、生命周期管理易复制、开放权重“后训练”存疑——据此把“后训练能否突破开放权重天花板”列为头号技术尽调问题；全球首部智能体安全强制国标 2026 年 6 月在华立项，存在 18–24 个月战略窗口。

八、重点专题：攻击基座大模型——专用性、客户飞轮、格局与重算规模

8.1 为什么它是独立品类、且通用模型替代不了：专用 vs 通用是“数量级”差距。
证据（2026，权威 / 官方）结果说明
OpenAI GPT-5.6-Cyber vs 同代通用 GPT-5.6-Sol95% vs 1.5%同一实验室，专用版完成 95% 高级攻防请求，通用版仅 1.5%
微软 MAI-Cyber-1-Flash（仅 5B 活跃参数）驱动 MDASHCyberGym 95.95%，超 Mythos 约 12 分、成本约一半小专用模型 + 多智能体系统击败巨型通用模型
Google Gemini 3.5 Flash Cyber / CodeMender（V8 引擎）55 个独特确认漏洞主网 Flash 47、Claude Opus 4.6 仅 36，含 10 个后两者漏掉的；2 小时挖出可绕 ASLR/W^X 的 RCE
arXiv 垂直基座研究（2026.5）垂直 Defense-LLM 单卡精度 0.904、误报 9.7%前沿通用模型白盒误报 10–50%、黑盒覆盖仅 4–8%；决定性能的是攻防数据与方法论而非参数规模
“通用大模型决定攻击的下限，专用攻防数据决定上限。”
8.2 客户全景与数据飞轮：中国版 Mythos 是横跨两个二级的共享底座。
U1 攻击 / 安全基座大模型（供能力 · 供引擎 · 供私有化底座）
本二级应用层U2 运营 / U3 漏洞 / U4 情报 / U5 治理产品公司
姊妹二级安全地运行 Agent：T1 治理 / T2 测试 / T3 身份 / T4 运行时 / T5 监控
软硬一体昇腾 / 飞腾一体机、AI 防火墙、安全探针、信创盒子
区域服务各省市本土 AI 安全服务商 / 集成商 / MSSP
国家直供国家漏洞库 / 关基 / 军工涉密 / 红蓝军 / 网络靶场
飞轮逻辑：客户越多 → 汇聚的真实攻防遥测、漏洞样本、攻击链越多 → 模型挖掘 / 研判能力越强 → 下游产品越好用 → 客户更多。由于横跨所有产品，基座方拥有任何单一应用厂商都不具备的全局攻击“上帝视角”，边际成本递减、边际能力递增，最终寡头化、赢家通吃。“所有安全产品都是它的客户，所有攻击数据都回流到它这里。”
8.3 为什么字节 / 智谱 / Kimi / MiniMax / 千问 / DeepSeek 最终不会来做“安全基座龙头”。
原因逻辑
① 机会成本 / 市场规模其主战略是万亿级 AGI/ASI 的消费与企业市场；安全基座 2030 中国约 190 亿，盘子小、项目制、毛利低、关系与资质驱动，不值得战略聚焦。
② 对美制裁顾虑（核心）做“国家攻击基座”需深度绑定国家攻防 / 涉密体系，极易被列入美实体清单，进而威胁其最看重的高端芯片、海外资本与全球市场、AGI/ASI 竞赛。因此它们选择做中立上游：开源通用模型供安全公司去做专用层，自己不碰敏感攻防与涉密客户。
③ 能力 / 数据错配安全需独家漏洞样本、攻防数据、顶级白帽、涉密资质、关基 know-how；通用实验室没有也不经济自建（8.1 已证：决定性能的是攻防数据而非规模）。
④ 商业模式冲突实验室卖规模化 token / MaaS；安全要私有化、项目制、等保涉密、7×24 责任兜底，基因不合。
证据闭环：(a) DoGNAVY 直接建在智谱 GLM-5.2 开源基座之上——智谱供通用底座、达酷诺威做安全专用层，正是该分工的现实样本；(b) Google 因双重用途把 Gemini Cyber 仅限政府与可信伙伴、不做通用商用；(c) Anthropic Mythos 走 Project Glasswing 防御联盟而非安全产品生意。通用基座厂普遍“供底座而不做安全生意”，这正是专业安全基座团队的结构性窗口。
8.4 重算规模：三口径阶梯 + 底座层渗透法（自下而上）。
先立方法论：同一赛道三种口径可差 3–10 倍，投委会须先对齐口径，避免“用卖 License 的算法估一个收租的生意”。
口径算法2030 量级评价
① 纯安全软件 License（最窄）只算攻击基座软件授权 / 订阅数十亿～百亿会系统性低估“底座 / 收租”型生意，此前 62 亿即此口径
② 底座层渗透（本报告中性基准）基座向两个二级下游产品收费 + 国家直供≈190 亿（127–268）符合“共享底座”产业本质，作为估值锚
③ 大盘×渗透·按运行量收租（最宽，上行期权）安全＝Agent 经济固定比例支出（Gartner：守护智能体占 Agentic AI 10–15%），计费由 License 转向按 Agent 运行量 / Token / 事件随大盘复利，2030 后仍续涨天花板由 Agent 大盘决定，是长期上行来源

结论：攻击基座是“用 AI 提升网络安全”里壁垒最高、增速最快（全口径 CAGR≈133%）、且唯一横跨两个二级、具数据飞轮的环节；其终局是 3–4 家寡头（约 2 纯软 + 1–2 软硬一体），龙头 2030 年单家收入有望达 87–106 亿。通用大模型厂因机会成本、制裁顾虑与主战略主动让出此位。国内卡位者达酷诺威（DoGNAVY 全球第三 / 开源第一）已验证“能力”关，接下来连过三道门：(1) 持续真实 0day/CVE 战绩；(2) 涉密 / 军工资质与关基标杆、软硬一体交付；(3) 从供模型到“基座 + 应用生态 + 数据飞轮”的商业闭环。
可证伪信号：F1 开源通用基座若把专用差距抹平（当前 95% vs 1.5%，短期不会），价值下沉到独家数据 / 场景 / 资质；F2 传统大厂绑定国产开源 + 收购头部团队，创业方多走并购退出；F3 自动化攻击受出口管制 / 武器化管控。跟踪：CyberGym/Big Sleep 排名、真实 CVE、昇腾软硬一体机中标、涉密资质、关基 / 军工订单、下游调用量与数据回流。
