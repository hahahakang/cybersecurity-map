AI-AMPLIFIED SECURITY · DEMAND-AXIS TAXONOMY · HORIZONTAL FOUNDATION LAYER

“用 AI 提升网络安全”行业图谱（五域重构版：需求轴统一 · 底座层横向）

二级不变；三级统一到“买方 / 作战域”一条轴，重排为 5 个三级、16 个四级能力；原“攻击基座大模型”不再与作战域平级，降为贯穿五域的横向“安全智能底座层”。关键事实校正：全球前沿攻击能力（Anthropic Mythos＝通用旗舰 Fable5 同权重、GPT‑Cyber、Gemini Cyber、MAI‑Cyber）均出自通用基座大厂、是通用旗舰的后训练衍生物且受控开放，独立公司不拼前沿权重，而以“专用小模型＋攻防数据＋多智能体系统＋涉密交付”立足。

核心结论：①五域同轴、MECE 干净——U1 自主攻防、U2 安全运营、U3 代码应用、U4 情报测绘反诈、U5 治理知识，全部按买方切分，合计严格等于 IDC 15.8→593.5 亿；“安全智能底座层”是横向技术层、不占编号、不重复计规模。②前沿攻击权重归通用大厂——Mythos 与通用版 Fable5 同一套权重、GPT‑5.6‑Cyber 建在 GPT‑5.6‑Sol 上、Gemini/MAI‑Cyber 同为旗舰后训练，且均受控开放；独立安全公司的真实生态位是“专用小模型＋独家攻防数据＋多智能体系统＋涉密 / 关基交付”（专用对通用 95%∶1.5% 的代差来自数据与工作流而非参数）。③横向底座层跨“用 AI 做安全＋保护 AI”两个二级，全口径中性约 190 亿元（127–268）、CAGR≈133%。④格局为 约 2 家纯软件 + 1–2 家软硬一体；字节 / 智谱 / Kimi / MiniMax / 千问 / DeepSeek 因机会成本、对美制裁顾虑与 AGI/ASI 主战略只做开源上游（DoGNAVY 建在 GLM‑5.2 上为现实样本）。⑤国内优质团队呈清华系 + GLM 生态聚集：真正自研垂直基座者仅华清未央（二进制 / 机器语言），自主攻防第一梯队为赛博昆仑、达酷诺威、360、安恒；全球首部智能体安全强制国标 2026 年 6 月在华立项，18–24 个月战略窗口。

一、划分原则与主轴线

主轴 · 产品类型（客户需求 / 买方不同）
五个三级全部按“谁付钱、保护 / 攻击对象是谁”切分，买方与预算各自独立、彼此 MECE；不允许把“技术层”与“作战域”混在同一级。
横向层 · 安全智能底座（不单列市场）
专用攻防小模型 / 攻防数据 / 智能体框架是贯穿 U1–U5 的技术层，上游接通用基座，价值内嵌于五域、另以全口径 TAM 单独观察，不重复计规模。
辅助视角 · 技术路线 / 产业链
调用通用 API / 开源续训 / 自研专用小模型；上游通用基座·算力·攻防数据 → 中游底座与智能体 → 下游软硬一体 / 托管 / 区域服务。

三、16 个四级能力（4 / 4 / 3 / 3 / 2）

U1 自主攻防（4）
1.1 自主挖洞 / 推理：陌生大库（含闭源二进制）自主定位 0day。
1.2 利用验证 / 攻击链：自动 PoC/Exploit、多步串联并证明“真能打进去”。
1.3 持续自动渗透 / BAS：7×24 暴露面验证、入侵与爆破模拟。
1.4 专用续训 / 私有化：注入攻防数据续训，涉密内网部署与攻防对齐。
U2 安全运营（4）
2.1 告警研判降噪：自动分诊定性，替代 L1。
2.2 自动威胁狩猎：主动检索潜伏威胁。
2.3 自主响应处置：自动执行 SOAR、隔离封禁。
2.4 多智能体 SOC：数字分析师团队闭环。
U3 代码应用（3）
3.1 代码审计：语义级 SAST/DAST/IAST 逻辑漏洞。
3.2 成分 / 供应链：SCA、SBOM、开源依赖风险。
3.3 自动修复 / 副驾：定位即生成补丁、安全左移。
U4 情报测绘反诈（3）
4.1 情报归因：IOC/TTP 自动关联与攻击者画像。
4.2 空间测绘：资产 / 暴露面地图与攻击面情报（FOFA 类）。
4.3 反深伪 / 反诈：识别 AI 钓鱼换脸、业务与电信反诈。
U5 治理知识（2）
5.1 智能合规 GRC：策略 / 等保 / 报告自动生成。
5.2 知识 Copilot：研判 / 运维 / 协同助手。

切分纪律：U1 是攻击者视角、证明可利用（买方＝红队 / 攻防 / 暴露面）；U3 是开发者视角、在 SDLC 左移找缺陷并修复（买方＝DevSecOps / 研发安全）——同一“漏洞”在进攻验证与开发修复两侧买方不同，故分属 U1、U3，消除旧版 U1/U3 重叠。

顺序三级细分入选 / 保留逻辑
1U1 自主攻防当前规模小但增速最高（中国 125%）、壁垒最高、确定性最强：专用对通用是数量级代差，海外攻击能力对我管制不供货构成刚性进口替代；横向底座层又横跨两个二级、空间被下游整体放大——属“高增速小规模”里唯一因壁垒＋底座属性上调为第一优先的赛道。
2U2 安全运营典型“高增速 × 大规模”：全球 150 亿美元、CAGR 21–25%，中国 2030 最大应用口袋（215.5 亿）。平台层易被微软 / 大厂捆绑，独立机会在差异化垂直智能体与托管运营（MSSP）。
3U3 代码应用“中速 × 大规模”的全球 122 亿美元存量盘，叠加 AI 修复（16.8%）等高增速子项；是攻防能力在开发侧最先变现的出口，优先看具备语义级 / 二进制分析能力的团队。
4U4 情报测绘反诈“中速 × 大规模”，但结构分化：攻击面测绘（FOFA 类）有数据网络价值、反深伪 / AI 反诈是新变量；通用反欺诈工具易被支付与云大厂内化，不押注独立巨头，保留结构性机会（不否定）。
5U5 治理知识全球 GRC 规模大但增速仅约 12%、门槛低、易被套件吸收、中国基数最小；不作为独立巨头重点，作为底座增值模块与 AI 治理政策期权跟踪，一旦出现 AI 原生合规爆款再升级（不轻易否定）。
价值判断结论： 确定有研究价值（重点）：U1、U2、U3——U1 是壁垒 / 弹性盘（第一优先），U2、U3 是规模盘； 结构性 / 有条件研究价值：U4（聚焦攻击面测绘、反深伪、AI 反诈与独立情报，规避被内化的通用反欺诈工具）； 确定不具“独立安全巨头”价值、但保留模块价值：U5 的独立工具形态（易被套件吸收，不等于赛道无价值，不否定）； 待进一步获取信息后分析：① U4 反深伪 / 反诈在中国市场的独立规模拆分（现有公开数据不足）；② U5 是否出现 AI 原生合规独立爆款（待验证）。整体研究顺序 U1 → U2 → U3 → U4 → U5。

10.3 为什么字节 / 智谱 / Kimi / MiniMax / 千问 / DeepSeek 最终不会来做“安全底座龙头”。
原因逻辑
① 机会成本 / 市场规模其主战略是万亿级 AGI/ASI 的消费与企业市场；安全底座 2030 中国全口径约 190 亿，盘子相对小、项目制、关系与资质驱动，不值得战略聚焦。
② 对美制裁顾虑（核心）做“国家攻防底座”需深度绑定国家攻防 / 涉密体系，极易被列入美实体清单，进而威胁其最看重的高端芯片、海外资本与全球市场、AGI/ASI 竞赛。因此它们选择做中立上游：开源开放权重供安全公司做专用层，自己不碰敏感攻防与涉密客户。
③ 能力 / 数据错配安全需独家漏洞样本、攻防数据、顶级白帽、涉密资质、关基 know-how；通用实验室没有也不经济自建（10.1 已证：决定性能的是攻防数据而非规模）。
④ 商业模式冲突实验室卖规模化 token / MaaS；安全要私有化、项目制、等保涉密、7×24 责任兜底，基因不合。
证据闭环：(a) DoGNAVY 直接建在智谱 GLM-5.2 开源基座之上——智谱供通用底座、达酷诺威做安全专用层，正是该分工的现实样本；(b) Google 因双重用途把 Gemini Cyber 仅限政府与可信伙伴、不做通用商用；(c) Anthropic Mythos 走 Project Glasswing 防御联盟而非安全产品生意。通用基座厂普遍“供底座而不做安全生意”，这正是专业安全团队的结构性窗口。

结论：安全智能底座层是“用 AI 提升网络安全”里壁垒最高、增速最快（全口径 CAGR≈133%）、且唯一横跨两个二级、具数据飞轮的环节；但须清醒——前沿攻击权重归通用大厂，独立公司的终局不是“自训前沿基座”，而是在开放权重上以专用小模型 + 攻防数据 + 系统 + 涉密交付形成 3–4 家寡头（约 2 纯软 + 1–2 软硬一体），龙头 2030 年单家收入有望达 87–106 亿。国内卡位者达酷诺威（DoGNAVY 全球第三 / 开源第一）、华清未央（自研二进制垂直基座）、赛博昆仑（顶级漏洞 + 微补丁，B 轮）已分别验证“能力 / 专用域 / 商业化”三关，接下来连过三道门：(1) 持续真实 0day/CVE 战绩；(2) 涉密 / 军工资质与关基标杆、软硬一体交付；(3) 从供模型到“底座 + 应用生态 + 数据飞轮”的商业闭环。
可证伪信号：F1 开放权重 + 后训练若把专用差距抹平（当前 95% vs 1.5%，短期不会），价值下沉到独家数据 / 场景 / 资质；F2 传统大厂绑定国产开放权重 + 收购头部团队，创业方多走并购退出；F3 自动化攻击受出口管制 / 武器化管控；F4 若通用大厂亲自下场做中国涉密安全生意（当前受制裁顾虑与主战略约束，概率低），独立底座逻辑需重估。跟踪：CyberGym/Big Sleep 排名、真实 CVE、昇腾软硬一体机中标、涉密资质、关基 / 军工订单、下游调用量与数据回流。
