安全地运行 Agent · 行业图谱三级细分

Secure Agent Operations — Agent 全生命周期安全防护体系
AI 安全四大板块之二 · 从"模型安全"延伸到"智能体行为安全"
① 输入接收→ ② 认知决策→ ③ 工具调用→ ④ 记忆检索→ ⑤ 执行输出→ ⑥ 运行时监控→ ⑦ 多Agent协作→ ⑧ 治理审计
1
输入层安全
Input Security
直接提示注入防护
识别并拦截恶意指令覆盖系统提示词
间接提示注入防御
检测网页/文档/RAG知识库中隐藏的注入载荷
越狱攻击防御
对抗角色扮演、编码绕过、多轮诱导等越狱
输入消毒与隔离
区分指令与数据，外部内容加标记/降权
多模态输入安全
图片/语音/视频中的隐写与跨模态注入检测
2
认知与决策安全
Cognition & Decision Safety
幻觉检测与抑制
事实一致性校验、虚构信息识别与拦截
目标对齐防护
防止目标漂移、奖励黑客、意图被恶意改写
规划链(Plan)安全
任务分解路径校验，阻断危险执行计划
推理完整性
CoT/ReAct链路防篡改，推理过程可验证
置信度评估
低置信决策自动转人工，避免自主误操作
3
工具调用安全
Tool/Action Security
最小权限管控
按Agent角色授予API/工具最小调用权限
工具沙箱隔离
代码执行/Shell/数据库操作在沙箱中运行
函数调用审计
Function Call参数校验、调用链全程留痕
高危操作拦截
转账/删除/外发/提权等动作需人工确认
越权调用检测
识别SSRF、水平/垂直越权、数据外传
4
记忆与知识安全
Memory & RAG Security
RAG投毒防护
知识库文档来源校验，防恶意知识注入
向量库安全
向量嵌入反演攻击防护、访问隔离与加密
记忆篡改检测
长期/短期记忆完整性校验，防持久化污染
多租户上下文隔离
会话/用户/租户间记忆严格隔离防串扰
知识来源验证
检索结果可信度分级、引用溯源
5
输出层安全
Output Security
敏感信息泄露防护
DLP检测，拦截密钥/PII/商业秘密外泄
恶意代码输出拦截
识别生成的漏洞利用、恶意脚本、木马
内容合规过滤
违法违规/有害内容/偏见歧视输出审查
AI水印与溯源
生成内容隐式水印、来源标识与取证
输出行为约束
限制Agent对外动作的范围、频率、额度
6
运行时防护
Runtime Protection (RASP for Agent)
Agent行为基线
建立正常行为画像，UEBA式异常识别
实时行为监控
动作序列、访问对象、资源消耗实时采集
自动熔断与回滚
异常时自动暂停、撤销已执行动作
动态权限收敛
按风险等级动态降权，Just-In-Time授权
资源与成本防护
防死循环、token耗尽、资源滥用攻击
7
多Agent协作安全
Multi-Agent Security
Agent身份认证
Agent间mTLS/身份凭证，防伪造Agent
通信加密与隔离
A2A通信加密、消息完整性、信道隔离
权限委派控制
任务委派时权限不放大、可追溯、可回收
编排链安全
Orchestrator工作流注入与劫持防护
共谋与操纵检测
识别多Agent被诱导合谋、互相背书
8
治理与审计
Governance & Audit
全链路行为日志
输入-推理-调用-输出完整审计链(Tamper-proof)
决策可解释性
每个动作可回溯原因，满足监管问责
Agent资产清单
影子Agent发现、登记、分级与生命周期管理
合规策略引擎
对齐《生成式AI管理办法》/EU AI Act等
红队评估
Agent对抗性测试、自动化攻防演练

⚠ Agent 区别于传统大模型的新型攻击面

提示注入→真实行动：Agent能调用工具，注入不再只是"说错话"，可直接执行转账、删库、外发邮件
混乱代理问题(Confused Deputy)：Agent被诱导利用其高权限访问用户无权访问的资源
RAG持久化投毒：污染知识库一次，所有调用该知识的Agent长期受控
多步攻击链放大：单步无害的动作被Agent串联成完整攻击链，传统单点规则失效
自主决策不可中断：自动化Agent在无人确认时高速执行，攻击窗口以秒计
跨Agent信任传递：一个被攻破的Agent通过协作链污染整个Agent集群
▎赛道阶段：从0到1，2026-2028爆发
当前Agent安全工具链极度碎片化，尚无绝对龙头。随着企业Agent大规模部署(预计2027年渗透率超40%)，运行时防护、工具调用管控、Agent审计将成为必选项，类比2015年的云安全(CNAPP)。
▎价值环节：运行时防护与治理审计壁垒最高
输入/输出过滤可被大模型厂商内置，易被管道化；而运行时行为监控、多Agent协作安全、全链路审计需要深度接入企业IT环境与业务上下文，是独立安全厂商的核心机会。
▎格局预判：基座厂商+独立厂商分层共存
基座大模型厂商提供"原生轻防护"(输入输出层)，独立Agent安全厂商主攻"企业级重防护"(运行时/工具/治理)，并通过安全大模型基座API实现能力复用，最终被平台型安全公司整合。
